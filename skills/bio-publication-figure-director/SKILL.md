# 生物学论文绘图总控

按已确认的任务范围选择工作方式。项目或期刊的明确要求优先，已有图件以原脚本、实际输入和输出规格为基线。

## 已有图的局部修改或重新导出（BUILD）

1. 找到生成当前图的脚本、输入和输出设置，核对要改的元素。标签若涉及单位、分母或对数变换，先核对底层数据能否支持新表述。
2. 在原绘图体系中修改指定元素，沿用其余参数与映射。沿用已有的运行入口和记录。按已确认的输出路径和格式重新导出，保留可复现的脚本和输入。
3. 实际查看最终图，用宿主的读图工具（Codex `view_image`，DeepSeek Harness `read_image`） 检查修改位置、裁切和相邻标注。交付 PDF 和 PNG 时，渲染 PDF 并查看 PNG，对照原图或输入核对数值、系列顺序、尺寸和应保留的样式。需要处理设备、字体嵌入或分辨率时，再查本宿主的 [导出技能](../bio-reporting-figure-export/SKILL.md)。

## 新图、重设计与审阅

- **ADVISE** 用已有证据回答图型或排版问题，经请求再实施。选择依据是变量结构、统计单位、样本量及图要支持的结论。
- **AUDIT** 对照现图、脚本、来源和图注，指出影响解读或交付的问题；按受影响项使用[质量检查清单](references/quality-gates.md)。
- **BUILD** 新建或重设计时先明确问题、实际输入、统计单位及目标输出。已有绘图栈优先，无既有体系时优先 R。新设计按[出版样式](references/publication-style.md)实现。简单单图复用现有记录；涉及多面板证据、派生数据或正式投稿交付时，依[完整绘图流程](references/full-figure-workflow.md)处理适用部分。

选取输入、比较单位或结论阈值前读取[科研适用范围](references/scope-notes.md)。保留原始数据、阴性与不确定结果，区分观察、关联和机制假设；统计图保留矢量元素和可编辑来源。基因组和育种场景按需查[专项路由](references/rice-bio-routing.md)。完整流程中的脚本位于本技能目录下。
