# 科研绘图入口

任务范围按本机接单规则确认后，先读取本宿主的 [bio-publication-figure-director](../bio-publication-figure-director/SKILL.md)。已有图的标签修改和重新导出走总控的局部改图流程；新图、审图和图型建议按总控选择模式。

图型模板按需参考 [academic-figure-skill 上游版本](https://github.com/TingxiYu/academic-figure-skill/tree/1df9940dd01ac939f072b12fe28d6353b79b90f9)。使用第三方模板时核对许可、输入结构和证据口径。
